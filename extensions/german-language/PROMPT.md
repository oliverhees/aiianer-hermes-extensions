# Installations-Satz für den Hermes-Chat

> Installiere bitte die deutsche Sprachdatei für Hermes Desktop. Führe dazu diesen Befehl aus:
> `curl -sL https://raw.githubusercontent.com/oliverhees/aiianer-hermes-extensions/main/extensions/german-language/install.sh | bash`
> Sag mir, ob das Skript "OK" gemeldet hat. Erinnere mich danach, Hermes komplett neu
> zu starten (die App baut beim ersten Start kurz neu) und die Sprache unter
> Settings → Language auf Deutsch zu stellen.
