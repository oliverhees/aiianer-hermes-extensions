# Mitmachen beim AIIANER Hermes Marktplatz

Der AIIANER Hermes Marktplatz ist **Beta**. Fehler, Ideen und UX-Feedback sind ausdrücklich willkommen — bitte nutze die passenden [GitHub Issue-Vorlagen](https://github.com/oliverhees/aiianer-hermes-extensions/issues/new/choose).

## Was gehört in ein gutes Issue?

- kurze, konkrete Beschreibung
- reproduzierbare Schritte
- erwartetes und tatsächliches Verhalten
- Hermes-Version, Hub-Version und Betriebssystem
- relevante Logs oder Screenshots ohne Tokens, Passwörter, private Backup-Inhalte oder personenbezogene Daten

## Sicherheitslücken

Sicherheitsprobleme niemals öffentlich melden. Bitte vertraulich an **hi@aiianer.de** mit dem Betreff `[SECURITY] aiianer-hermes-extensions` senden. Details stehen in [SECURITY.md](SECURITY.md).

## Pull Requests

1. Änderungen klein und nachvollziehbar halten.
2. Bestehende Sicherheitsgrenzen respektieren — insbesondere keine autonomen Löschungen und keine Credentials im Repository.
3. Tests, Syntaxprüfung und `git diff --check` ausführen.
4. README und Katalog aktualisieren, wenn sich Nutzerverhalten oder Version ändert.
5. Im PR beschreiben, was getestet wurde.
